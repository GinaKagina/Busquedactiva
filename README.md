# **🔬 Investigación Conectada: Acción y Evidencia**

Bienvenido al repositorio oficial del proyecto **Investigación Conectada**, un sitio web didáctico e interactivo diseñado para transformar la manera en que se aprenden las metodologías activas y las técnicas de búsqueda avanzada de información.

Este proyecto fue concebido para superar la investigación pasiva, ofreciendo a estudiantes y académicos herramientas visuales para comprender y aplicar el método científico en la era digital.

## **🎯 Objetivo del Proyecto**

El objetivo principal de esta plataforma es guiar a los usuarios en el dominio de dos competencias fundamentales:

1. **Metodologías Activas:** Comprensión de la Investigación-Acción Participativa (IAP), la investigación en el aula y el Aprendizaje-Servicio (ApS).  
2. **Búsqueda Avanzada de Información:** Dominio de la sintaxis lógica, operadores booleanos, uso de tesauros (lenguaje controlado) y estrategias como el rastreo de citas (Snowballing).

## **✨ Características Interactivas (UX/UI)**

El sitio ha sido desarrollado bajo principios de *diseño instruccional*, incorporando los siguientes componentes interactivos:

* **🔄 Espiral Cíclica (IAP):** Gráfico interactivo para explorar las fases de Planificación, Acción, Observación y Reflexión.  
* **🖱️ Simulador Booleano (Diagrama de Venn):** Herramienta visual en tiempo real para entender el impacto de los operadores AND, OR y NOT en las búsquedas documentales.  
* **🎴 Flip Cards 3D de Sintaxis:** Tarjetas giratorias que explican el uso de comillas, asteriscos y paréntesis, con un **botón integrado para copiar al portapapeles** las ecuaciones de ejemplo.  
* **🎛️ Simulador de Filtros:** Panel lateral dinámico para aprender la importancia de los limitadores por fecha, tipo de documento y campo de búsqueda.  
* **📈 Línea de Tiempo de Rastreo de Citas:** Animación para comprender el concepto de *Citation Snowballing* (hacia atrás y hacia adelante).  
* **🔗 Fuentes de Información Directas:** Botones enlazados a bases de datos de acceso abierto, alto impacto y acceso regional (Google Académico, Scopus, SciELO, etc.).  
* **🎬 Reproductor Audiovisual Seguro:** Integración *privacy-enhanced* de YouTube para evadir restricciones de cookies de terceros.

## **🛠️ Tecnologías Utilizadas**

Este proyecto es estático (One-Page) y no requiere de un servidor backend para funcionar, lo que garantiza una carga ultra rápida y una compatibilidad universal.

* **HTML5:** Estructuración semántica de la información.  
* **Tailwind CSS (CDN):** Framework de utilidades para un diseño moderno, minimalista y 100% responsivo (adaptable a móviles y tablets).  
* **Vanilla JavaScript:** Lógica de interacciones, Scrollspy del menú de navegación, animaciones SVG y gestión del portapapeles.  
* **Lucide Icons:** Conjunto de iconos vectoriales limpios y escalables.
